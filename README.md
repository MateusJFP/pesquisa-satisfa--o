# 📊 Pesquisa de Satisfação - TudoWeb

Projeto em Python que coleta a opinião de clientes sobre o atendimento.

## 🚀 Funcionalidades
- Coleta nome, idade e opinião
- Classificação:
  - 1: Excelente
  - 2: Bom
  - 3: Ruim
- Exibe:
  - Total de respostas EXCELENTE
  - Total de respostas RUIM

## 🧪 Testes
Realizado com 10 entrevistados para validação.

## ▶️ Como executar
```bash
python pesquisa.py
